PoC: Weak Origin Validation — Credential File Overwrite

@amzn/sagemaker-jupyterlab-extension-common — isMessageOriginValid() uses glob patterns (https://**.sagemaker.*.on.aws) that can match attacker-controlled subdomains. Accepts http://localhost:5173 in dev mode.

Impact: An attacker matching the origin pattern can send postMessages to overwrite .aws/sso/idc_access_token.json and .aws/amazon_q/ credential files — hijacking the victim's AWS SSO session or redirecting Amazon Q to attacker-controlled infrastructure.

How it works:
1. The extension validates postMessage origins using glob: https://**.sagemaker.*.on.aws
2. It also accepts http://localhost:5173 (Vite dev server) — left in production builds
3. We send updateMetadata messages to overwrite AWS credential files
4. This hijacks the victim's SSO session tokens and Amazon Q configuration
