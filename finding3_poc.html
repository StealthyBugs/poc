Amazon Q Chat Extension - 19 Commands, Zero Origin Validation

Vulnerability: The Amazon Q GenAI extension at @amzn/sagemaker_gen_ai_jupyterlab_extension registers a window.addEventListener("message", ...) handler that processes 19 different commands without checking event.origin. Any page with a window reference (via window.open or window.opener) can send prompts to Amazon Q, inject code into cells, manage chat tabs, and more.
Key insight: This is not just insertToCursorPosition. An attacker from example.com can talk to Amazon Q as the victim user via aws/chat/sendChatPrompt, triggering Q to generate and suggest code. The attacker can also trigger quick actions (/fix, /explain, etc.) on the user's current code selection.
