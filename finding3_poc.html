Finding 3: insertToCursorPosition via postMessage

Amazon Q Chat Extension - No Origin Validation

Vulnerability: The Amazon Q GenAI extension registers a window.addEventListener("message", ...) handler that processes the insertToCursorPosition command without checking event.origin. Any page with a window reference can inject arbitrary code into the active notebook cell.
Limitation: The injected code is inserted into the cell but NOT auto-executed. The user must manually run the cell. This is why Finding 3 was downgraded to a code quality issue. However, when chained with social engineering or Finding 4 (file write), impact increases.
