Finding 4: Doc Manager postMessage — No Origin Validation

About This Test

The @amzn/sagemaker-ui-doc-manager-jl-plugin registers a window.addEventListener("message", ...) handler that processes file operations (OpenFile, OpenUntitledFile, OpenOrCreateFile) without checking event.origin.

Attack model: This test demonstrates the chain vector — it should be loaded inside JupyterLab (e.g., via Simple Browser or as notebook output) where window.parent reaches the main JupyterLab window.

Standalone test: If running outside JupyterLab, you can also test via the browser console in the JupyterLab tab directly (see Manual Test section below).

Test 1: Create text file via OpenOrCreateFile

Creates finding4_proof.txt with proof content.

Test 2: Create HTML file via OpenUntitledFile

Creates an untitled .html file with JS payload. If served by Jupyter, the JS executes (stored XSS).

Test 3: Open existing file via OpenFile

Sends OpenFile for finding4_proof.txt (must exist first — run Test 1).

Log

Manual Console Test

Paste this into the browser console while on the JupyterLab/SageMaker Studio tab:

// Creates a file at the specified path with attacker-controlled content
window.postMessage({
  type: "sagemaker:nbevent:OpenOrCreateFile",
  payload: {
    type: "file",
    path: "finding4_console_test.txt",
    content: "FINDING 4 CONFIRMED\\nFile created via postMessage without origin validation.\\nTimestamp: " + new Date().toISOString(),
    format: "text"
  }
}, "*");

If the file appears in the file browser and auto-opens, the vulnerability is confirmed.
